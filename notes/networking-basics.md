Networking Basics

1. What is a Computer Network?

A computer network is a group of computers and devices connected together so they can communicate and share information.

Examples:

- Computers
- Smartphones
- Servers
- Routers
- Printers

2. What is an IP Address?

An IP address is a numerical address used to identify a device on a network.

Example:

"192.168.1.10"

There are two common versions:

- IPv4
- IPv6

3. What is a Port?

A port is a logical communication endpoint used by network services.

Some common ports:

Port| Protocol| Common Use
22| SSH| Secure remote access
53| DNS| Domain name resolution
80| HTTP| Web traffic
443| HTTPS| Secure web traffic

4. What is TCP?

TCP stands for Transmission Control Protocol.

It provides reliable communication between devices.

TCP makes sure that data is delivered correctly and in the correct order.

5. What is UDP?

UDP stands for User Datagram Protocol.

UDP is faster than TCP but does not provide the same level of delivery guarantees.

6. What is DNS?

DNS stands for Domain Name System.

DNS translates domain names into IP addresses.

For example:

"google.com" → an IP address

7. What is a Router?

A router connects different networks and forwards data between them.

A home router commonly connects a local network to the Internet.
